# Java Project
Java (the programming language)

Java is a high-level, object-oriented, general-purpose programming language created by James Gosling at Sun Microsystems and released in 1995. It is now owned by Oracle. Its main strengths are:

Platform independent: code compiles to bytecode that runs on any system with a Java Virtual Machine (JVM) (“write once, run anywhere”).
Object-oriented: built around classes and objects.
Secure and robust: automatic memory management (garbage collection), strong typing, and exception handling.
Multithreaded: supports running several tasks at once.
Widely used for web backends, Android apps, enterprise software, and big data tools.

java.lang (the package)

java.lang is the core package of the Java standard library. It is imported automatically, so you never need an import statement for it. It contains the fundamental classes of the language:

Object: the root class of every Java class
String, StringBuilder, StringBuffer: text handling
Wrapper classes: Integer, Double, Boolean, Character, etc.
Math: mathematical functions
System: input/output streams and system properties
Thread and Runnable: multithreading
Exception, Throwable, Error: exception handling
Class: runtime information about classes
